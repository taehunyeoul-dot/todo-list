# 할 일 목록 (개인용 PWA)

폴더(상위 목록)별로 할 일을 정리하는 개인용 웹앱입니다. Apple 미리알림 스타일의 UI로,
아이폰 사파리에서 홈 화면에 추가해 앱처럼 사용합니다.

## 주요 기능

- **상위 목록(폴더)**: 이름·색상·아이콘을 골라 생성, 필요 없으면 삭제 (예: 거래처 사장님, 유튜브, 클로드 대시보드)
- **할 일 관리**: 목록 안에서 할 일 추가, 완료, 삭제
- **완료 메모**: 완료 처리할 때 "어떻게 처리했는지" 메모를 남길 수 있음
- **날짜 표시**: 생성일과 완료일이 각 할 일에 표시됨
- **완료 목록**: 완료된 항목은 아래 완료됨 섹션으로 이동, 보기/가리기 가능
- **백업/복원**: 왼쪽 위 ⚙︎ 버튼에서 JSON 파일로 내려받기/불러오기
- **오프라인 지원**: 한 번 열어두면 인터넷 없이도 동작 (서비스 워커 캐시)

## 아이폰 홈 화면에 추가하기

1. 사파리에서 앱 주소를 연다
2. 공유 버튼(□↑) → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행하면 전체 화면 앱처럼 사용 가능

## 데이터 저장 위치

모든 데이터는 **이 기기 브라우저(localStorage)에만** 저장됩니다. 서버로 전송되지 않습니다.
기기를 바꾸거나 사파리 데이터를 지우면 사라지므로, 가끔 ⚙︎ → 백업 파일 내려받기로 보관하세요.

## 기술 구성

- 단일 `index.html` (프레임워크 없음, 순수 HTML/CSS/JS)
- `manifest.webmanifest` + `sw.js` — PWA(홈 화면 설치, 오프라인)
- `icon-180/192/512.png` — 홈 화면 아이콘
- 사파리 터치 안정화: 핀치/더블탭 확대 차단, 가로 쏠림 방지, 입력창 포커스 확대 방지
