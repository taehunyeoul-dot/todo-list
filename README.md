# 할 일 메모 (개인용 PWA)

아이폰 메모의 속도감으로 "할 일만" 관리하는 개인용 웹앱입니다.
갑자기 떠오르는 생각은 아이폰 메모에, 할 일은 이 앱에 — 플랫폼을 분리해 쓰는 것이 콘셉트입니다.

접속 주소: https://taehunyeoul-dot.github.io/todo-list/

## 사용 방식

앱을 열면 두 가지 중 하나를 선택합니다.

### 메모하기
- 누르는 즉시 새 메모가 시작됩니다. 저장 버튼 없음 — 입력하는 대로 실시간 저장됩니다.
- 메모는 체크박스 목록 구조입니다. 각 항목 아래에 "처리 결과"를 적는 작은 박스가 항상 있습니다.
- 체크하면 완료 날짜가 표시되고, 메모 상단에는 작성 날짜가 표시됩니다.
- 왼쪽 하단 **라벨**: 분류 선택 팝업 (라벨 추가·삭제·이름변경 가능, 8자 이내, 동일 크기 버튼 2열)
- 오른쪽 하단 **새 메모**: 지금 메모를 두고 바로 다음 메모 시작
- 내용 없이 나가면 빈 메모는 자동으로 정리됩니다.

### 메모찾기
- 맨 위 검색: 단어로 할 일·처리 결과·라벨을 검색
- 그 아래 라벨 필터: 라벨을 누르면 해당 라벨의 메모만 표시
- 미완료 할 일이 남은 메모는 **진행 중**(위), 전부 체크된 메모는 **완료**(아래)
- 메모를 누르면 메모하기 화면으로 열립니다.

## 아이폰 홈 화면에 추가

사파리에서 접속 → 공유(□↑) → **홈 화면에 추가**. 전체 화면 앱처럼 실행됩니다.

## 데이터

모든 데이터는 이 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
첫 화면 하단의 **백업 · 복원**으로 JSON 파일 보관/복구가 가능합니다.

## 기술 구성

- 단일 `index.html` (프레임워크 없음, 순수 HTML/CSS/JS)
- `manifest.webmanifest` + `sw.js` — PWA (홈 화면 설치, 오프라인 동작)
- `icon-180/192/512.png` — 홈 화면 아이콘
- 사파리 터치 안정화: 핀치/더블탭 확대 차단, 가로 쏠림 방지, 입력 포커스 확대 방지, 키보드 위로 하단 바 이동(visualViewport)
