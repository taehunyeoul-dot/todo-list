# 할 일 메모 (개인용 PWA)

아이폰 메모의 속도감으로 "할 일만" 관리하는 개인용 웹앱입니다.
글래스모피즘(유리 카드 + 그라데이션 블롭) 디자인.

접속 주소: https://taehunyeoul-dot.github.io/todo-list/

## 사용 방식

첫 화면에서 **메모하기 / 메모찾기** 중 하나를 선택합니다.

- **메모하기**: 즉시 새 메모 시작, 실시간 저장. 체크박스 목록 + 항목별 "처리 결과" 박스.
  왼쪽 하단 라벨, 오른쪽 하단 새 메모. 작성일·완료일 자동 표시. 빈 메모는 자동 정리.
- **메모찾기**: 단어 검색 → 라벨 필터 → 진행 중(위) / 완료(아래). 메모 클릭 시 메모하기로 열림.
- **라벨**: 팝업에서 선택. 추가·삭제·이름변경 가능(8자 이내, 2열 동일 크기).

## 데이터 3중 보관

| 층 | 방식 | 보호 범위 |
|---|---|---|
| 1 | localStorage 즉시 저장 | 평상시 사용 |
| 2 | 자동 스냅샷 (하루 1회, 최근 7일) | 실수로 지웠을 때 되돌리기 |
| 3 | GitHub 비공개 Gist 클라우드 동기화 | 홈 화면 앱 삭제·기기 분실·기기 교체 |

- 동기화는 첫 화면 하단 **동기화**에서 GitHub 토큰(classic, gist 권한만)을 붙여넣으면 연결됩니다.
- Gist는 수정 이력을 모두 보관하므로 사실상 무제한 버전 백업이 됩니다.
- 수동 파일 백업/복원도 **데이터 보관**에서 가능합니다.

## 중요: iOS 저장 공간 특성

iOS에서 **사파리 탭과 홈 화면 앱은 저장 공간이 분리**되어 있습니다.
사파리에서 쓴 메모는 홈 화면 앱에 보이지 않고, 그 반대도 마찬가지입니다.
또한 **홈 화면 앱 아이콘을 삭제하면 그 안의 데이터도 함께 삭제**됩니다.
→ 동기화를 켜 두면 어느 쪽이든 클라우드에서 복구되므로 안전합니다.

## 아이폰 홈 화면에 추가

사파리에서 접속 → 공유(□↑) → **홈 화면에 추가**.
아이콘을 새로 바꾸려면 기존 아이콘을 삭제 후 다시 추가해야 합니다(iOS가 아이콘을 캐시함).
삭제 전에 동기화 연결 또는 백업 파일 저장을 먼저 할 것.

## 기술 구성

- 단일 `index.html` (순수 HTML/CSS/JS, 프레임워크 없음)
- `manifest.webmanifest` + `sw.js` — PWA (홈 화면 설치, 오프라인)
- `icon-180/192/512.png` — 코발트 블루 체크 아이콘
- 글래스모피즘: backdrop-filter 유리 카드, 유기적 블롭 배경, 블루→바이올렛 그라데이션
- 사파리 터치 안정화: 핀치/더블탭 확대 차단, 쏠림 방지, 키보드 위 하단 바(visualViewport)
- 동기화: GitHub REST API(Gist), 최신 시각 우선(last-write-wins), 디바운스 자동 업로드
